# Demo script — 60-sec prototype demo (Playcast)

> Single-take. Jenny in frame for opener + close. Screen capture covers the middle.
> Submission requires the demo video to be publicly shareable (judging weights
> social engagement). Tweet-shaped from line one.

**Total runtime:** 60 seconds, hard cap.
**Recording surface:** OBS (Playcast). 1080p. Mic check before rolling.
**Aspect ratio:** 16:9 for the form, but record vertical-safe (action in center 1080×1080) so it crops to a square for Twitter/LinkedIn.

---

## Pre-roll checklist (30 sec before recording)

- [ ] CharisMaster app open in tab 1, AI Studio session ready, three-mode toggle visible.
- [ ] Save Me input pre-filled in tab 2 (don't waste demo seconds typing).
- [ ] Coach Me input pre-filled in tab 3.
- [ ] Ship Me input pre-filled in tab 4 with: this repo's GitHub URL + `docs/one-pager.md` text + a 1-page AI build chat transcript + builder name "Jenny Ruan".
- [ ] One pre-cached result per mode open in tabs 5/6/7 as fallback if live gen stalls.
- [ ] Jenny in frame, ring light on, clean background.
- [ ] Phone timer at 60 seconds.

## Script — verbatim

### 0:00–0:07 (Jenny on camera, direct address) — 7s

> "I've bombed pitches. I've bombed stand-up sets. I've shipped products no one heard about. The common thread — **you can't see what you're sending into the room.**"

**Tone:** flat, honest, no smile yet. Look at lens not script.
**Cut:** match-cut to screen capture as "into the room" lands.

### 0:07–0:11 (Screen capture, THREE mode-cards visible) — 4s

> "CharisMaster. Three modes. One engine."

Mouse cursor sweeps across the 🎓 Coach Me / 🎯 Save Me / 🚀 Ship Me cards.

### 0:11–0:23 (SAVE ME mode + screen-size flip) — 12s

Click 🎯 Save Me.

Voiceover:
> "I'm pitching Stanford GDG judges in 90 minutes. 60 seconds. I want VC meetings."

Fields pre-filled. Click **Generate**. Graphical one-pager renders.

Camera zooms in. Voiceover overlays:
> "Opening. Beats with timing. Close and ask. Two comebacks."

Quick beat: flip screen-size toggle 🖥 Desktop → 📱 Phone.

> "**Fold it. Pocket it. Go.**"

### 0:23–0:34 (COACH ME mode + REFINE) — 11s

Cut to tab 3. Click 🎓 Coach Me. Field pre-filled with "How to master the Demo Day pitch." Click **Generate**.

Camera holds. Voiceover:
> "Three things the masters do — real YC pitches. Three traps. Three drills today."

Quick beat: paste a second reference URL into the **Refine** panel, type "Add Sam Altman." Hit Refine.

> "Missing Sam Altman. I refine. 8 seconds. Old version saved."

### 0:34–0:51 (SHIP ME mode — THE META MONEY SHOT) — 17s

Cut to tab 4. Click 🚀 Ship Me. Voiceover:
> "And one more. **Ship Me.**"

The pre-filled fields are visible: this repo's GitHub URL, the design doc text, an AI build chat transcript, the name "Jenny Ruan."

Voiceover, slower:
> "I paste in this repo. The design doc I wrote at noon. The chat transcript of building CharisMaster today. My name."

Click **Generate**. Graphical launch page renders for CharisMaster itself.

Camera zooms slowly into the generated launch page. Voiceover:
> "**CharisMaster just wrote its own launch page. The page I'm submitting to this hackathon — was generated by the submission.**"

Beat. Hold on the rendered Ship Me page.

> "Built solo, three hours, Gemini multimodal. The product writes itself."

### 0:51–0:60 (Jenny back on camera, CTA) — 9s

> "**Try yours at charismaster.com.** Coach you. Save you. Ship you."

**End frame:** logo + URL hold for 1 second. Final frame is shareable as a still.

## What to do if the live demo breaks during recording

1. **Don't redo the whole take.** Cut. Reset to the broken step. Re-record from there. Edit later.
2. **Fall back to pre-cached result.** Three pre-cached results are sitting in the third tab from the pre-roll checklist. Voiceover phrases "Here's what it generated for me earlier today" if needed.
3. **Don't apologize on camera.** Confident delivery beats perfect delivery in the social engagement score.
