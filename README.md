## One-paragraph pitch

Performers can't watch themselves perform. Founders bomb pitches they would
have nailed if they'd seen yesterday's tape. Builders ship products no one
hears about. Three different shapes of the same problem: you can't see what
you're sending into the room. **CharisMaster** is the AI apprentice for all
three — one Gemini multimodal engine, three graphical one-pager outputs. The
launch page on this submission was generated by CharisMaster itself.

## Three modes (v0)

| Mode | Trigger | What you get |
|---|---|---|
| 🎓 **Coach Me** | "I want to get better at X" | Graphical how-to one-pager: 3 master principles + 3 traps + 3 drills + watch-next. Reusable. |
| 🎯 **Save Me** | "I have X tomorrow" | Graphical script one-pager: opening + beats with timing marks + close + ask + comeback lines. Disposable. Fold and pocket. |
| 🚀 **Ship Me** | "I built X, help me launch it" | Graphical launch one-pager: name + tagline + builder + description + feature list + links + use guidance. Generated from your design docs / AI build chat / repo URL. |

All three modes:
- Render as **graphical one-pagers** (Nano Banana flourishes + structured layout).
- Offer a user-selected **screen-size toggle** on the output page: 📱 phone / 📲 tablet / 🖥 desktop / 🖨 print.
- Support **iterative refinement** — drop in more references or a free-text note ("make the close more aggressive"), CharisMaster regenerates while preserving what you didn't critique.
- Produce a **shareable PNG** with a one-click Twitter/LinkedIn draft.

## Why Gemini

- **Native video understanding** — analyzes your delivery + reference performances in one multimodal call. OpenAI and Anthropic cannot do this today.
- **Long context** — ingests your video + 3 full reference clips + your design docs + JSON output schema in a single call. Zero RAG, zero chunking.
- **YouTube URL ingestion** — reference corpus is just public URLs; Gemini reads them directly. Zero pre-download.
- **Nano Banana image-gen** — every one-pager gets a hand-illustrated header generated inline.
- **Multi-input flexibility** — Ship Me takes design docs, AI chat transcripts, GitHub URLs, and freeform notes in the same call.
